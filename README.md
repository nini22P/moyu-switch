## 安装方法

注意：由于视频字幕硬编码在视频中，体积较大，请按需下载。

### NS 实机（Atmosphere）

1. 确保实机已破解并安装大气层（Atmosphere）
2. 下载汉化补丁和汉化视频包（可选）并解压。
3. 将 SD 卡插入电脑，在 SD 卡中创建目录 `atmosphere/contents/0100a89019eec000`
4. 将解压得到的 `exefs` 和 `romfs` 目录复制到 `atmosphere/contents/0100a89019eec000` 目录中。

### 模拟器

1. 下载汉化补丁和汉化视频包（可选）并解压。
2. 在模拟器内右键游戏打开 mod 目录。
3. 在 mod 目录下创建任意目录，如 `汉化补丁`。
4. 将解压得到的 `exefs` 和 `romfs` 目录移动到上一步创建的目录中。
